## Evidence manifest and source ownership

Suggested `ExtractionEvidenceManifest`, separately versioned from the source document: raw original SHA-256/byte length/media type; normalized source ID/version/fingerprint when available; extractor/normalizer/library versions; exact pinned retrieval identity; bounded evidence entries; counts/coverage/loss notices. Absence of an entry means “not inventoried,” not proof that the source has no figure/table. An unsupported or interrupted import may retain a raw-byte-bound loss manifest without fabricating readable source blocks.

Each entry has a deterministic ID, type (`text`, `equation`, `table`, `figure`, `supplement-reference`), original label/caption if present, original locator, extraction method and state (`retained`, `partial`, `not-extracted`, `unavailable`). Record confidence **basis** separately: source structural markup, raw PDF text, heuristic layout, or user transcription. These are provenance classes, not calibrated probabilities or scientific-validity scores. Missing payload, missing coordinates, incomplete region coverage and unavailable original bytes are independent conditions. A caption is not recovered pixels; a source image URL is a reference, not a checked local image.

Locate PDF evidence by 1-based physical page plus explicit coordinate space, page view box, rotation, user unit and viewport policy. Retain raw PDF-user-space regions and use PDF.js transforms for display; do not assume all PDFs are unrotated, start at `(0,0)` or use screen pixels. Printed page labels, if retained, are additional labels, not array indices. HTML evidence uses original element ID/structural locator plus nearby raw text and input digest; it has no invented PDF page or pixel box. Repeated quotes/IDs must produce ambiguity rather than select a convenient occurrence. [W3C Web Annotation §§4.2.4–4.2.5](https://www.w3.org/TR/annotation-model/#selectors) provides useful quote/position selector distinctions and warns that position selectors are brittle under edits; use its concepts without adopting a general SVG/selector execution engine.

An attachment owns its **own** byte hash, media type, edition/version and rights record, plus a relation to the parent source fingerprint and the exact link/annotation that introduced it. Same filenames or URLs do not establish same content. A supplement for arXiv v1 must not silently satisfy a requirement for v2. [arXiv version policy](https://info.arxiv.org/help/versions.html) preserves numbered versions; its [ancillary-file documentation](https://info.arxiv.org/help/ancillary_files.html) says ancillary files belong to particular article versions and can differ across them. Existing arXiv `vN` pinning is therefore useful but does not replace an attachment digest.

## Retain each modality honestly

- **Text:** preserve raw fragments and reconstruction operations. Keep text omission/unsupported glyphs/read-order uncertainty visible. A clean paragraph does not imply exact reading order or complete coverage.
- **Equations:** preserve source-provided TeX/MathML annotations verbatim alongside label and locator; render through the existing KaTeX path (`trust:false`, bounded expansion), with raw notation fallback. [W3C MathML annotation framework](https://www.w3.org/TR/MathML3/chapter5.html#mixing.semantic.annotations) distinguishes expressions from alternate representations/annotations. Rendering a supplied annotation does not prove semantic equivalence. PDF equation-like text remains text with loss and original-page return; do not let a model fill missing symbols into an “original equation.”
- **Tables:** first support explicit structured HTML rows/cells, headers, spans, caption, footnotes and source strings. Preserve blanks, merged cells, unavailable symbols and uncertainty notes. Reject unsupported spans or retain a partial original table rather than guessing alignment. Numeric ScientificAsset promotion is a separate inspected conversion with units/missing policies, not a side effect of extraction. [NISO JATS table-wrap definition](https://jats.nlm.nih.gov/publishing/tag-library/1.4/element/table-wrap.html) includes captions/footnotes and permits a table represented as a graphic; do not equate a table label with available numeric cells. Defer PDF numeric table reconstruction until a reviewed adapter has cell-level references and independent tests.
- **Figures/microscopy:** use original PDF page pixels or a checked, rights-admitted image, retaining caption, source coordinates and original digest. A crop is a declared derived view of the original, never an independently acquired image. Do not infer micrometre calibration from a screenshot, PDF user units or apparent scale-bar shape; use the existing spatial calibration/unknown-scale distinction. Keep microscopy images distinct from diagrams and model-generated illustrations.
- **Supplement references:** retain label, relation, original resolved URL/attachment name, source locator, media/size if supplied, retrieval state, rights/access status and meaningful unavailable reason. A reference is not the material itself. [NISO JATS supplementary-material](https://jats.nlm.nih.gov/publishing/tag-library/1.4/element/supplementary-material.html) explicitly distinguishes external resource metadata from the described object, while regular figure/table elements may also be flagged supplementary. This informs a format adapter; implementing a full JATS parser is not necessary in the first increment.

arXiv itself describes HTML conversion as experimental and notes that not every paper converts successfully. [Official accessible-HTML explanation](https://info.arxiv.org/about/accessible_HTML.html). Prefer structure when available, preserve conversion errors and return to the pinned PDF; do not call HTML an independent ground truth for correcting its PDF counterpart.

## Corrections are derived interpretations

Keep the original SourceDocument/raw bytes and its quotations immutable. A correction overlay records base source/manifest hash, target evidence/locator, before-value/hash, user-authored replacement, reason, author class and revision/parent revision. Validate the target and precondition before applying it; stale edits, ambiguous regions or replaced source bytes cannot silently rebase. Show original and correction side by side and make rollback possible.

Prefer an overlay note/transcription in the first implementation. If downstream analysis later consumes a corrected document/table, create a new explicitly derived interpretation identity linked to the original; invalidate outputs bound to the previous interpretation. Never validate corrected wording as a quotation from an unchanged original block. A typed correction does not itself prove source fidelity: mark user transcription, and retain the supporting original region. Model-proposed explanation remains an authored proposal, cannot write the original extraction layer, and requires no paid creation for basic correction. Missing cells remain missing until a user supplies an explicitly derived value, not a fabricated observation.

## Explicit supplement retrieval and rights

MVP: references are inert on import/mount/reopen. Offer **inspect link**, **open at source** (external navigation, not an app-verified bounded download), **select local file**, and, only for a registered reviewed destination, **retrieve this attachment**. Show recipient/domain, exact parent/version/link, expected type/size/hash, rights/access status and what is sent. Retrieval sends a registered reference ID and necessary public locator, never automatically uploads the private paper, all attachments, corrections or model context. Selection/confirmation remains distinct from binding a downloaded table/image to an executable view.

Reuse PP106 broker consent/identity principles, not its fake result as an actual downloader. Its deterministic-demo adapter cannot establish access to a real supplement. A minimal real read-only retrieval adapter can be limited to **one already admitted author-deposited file**, e.g. [Chew FAIRDOMHub 2212 version 1](https://fairdomhub.org/data_files/2212?version=1), pinned in [PP090 admission](statistical-data-sources.md). That original CC0 workbook has a recorded 127,343-byte edition/digest; recheck its actual redirect destinations and access terms before enabling the endpoint, require the pinned digest and return a mismatch on changes. XLSX remains a passive unsupported-format attachment unless a separate reviewed converter is added; do not execute formulas/macros or pretend existing CSV import parses a workbook. Local CSV/JSON/PDF paths reuse existing adapters.

Bound actual streamed and decoded bytes, timeout, redirects, media/magic, attachment count and total retained size; no archive recursion, authentication forwarding, cookie scraping or content from arbitrary model URLs. Keep failed references with a return-to-original action. Private/expired/403 responses are unavailable, not permission to bypass access. arXiv ancillary URLs need a narrowly reviewed version-bound path adapter; the present `/abs|html|pdf|api/query` allowlist is intentionally insufficient. The [official arXiv API terms](https://info.arxiv.org/help/api/tou.html) also impose legacy API request pacing across machines; explicit user clicks do not excuse unbounded parallel retrieval.

Rights attach to each edition/object; availability and attribution alone do not authorize rebundling. [arXiv license documentation](https://info.arxiv.org/help/license/index.html) distinguishes submitter licenses and notes versions can differ. [PMC's official OA-subset guidance](https://pmc.ncbi.nlm.nih.gov/tools/openftlist/) states that not every PMC article is reusable, and specifies approved automated retrieval services. Keep article, figure, supplement, code/data and third-party exceptions separate. Unknown rights stay unknown; local inspection is not a declaration of ownership or public-export permission. Bundles default to references/derived notes, with raw source/attachments opt-in and existing privacy disclosures; PDF/attachment deletion removes only the relevant owner's references, preserving shared originals.
