# Generated figure quality (PP-098)

Compiled source can still produce an empty, clipped or unusable figure. This gate checks engineering quality before a new Muse candidate can be saved. It remains separate from scientific evidence, which stays **unverified**.

## One renderer, bounded scenarios

`GeneratedFigureDisplay` renders the same validated SDK frames in the product and `/artifact-lab`. The lab is an explicit, provider-free diagnostic page with authored fixtures, not another model endpoint. It uses the production compiler and fresh-compile-gated execution bridge. No generated code receives DOM, browser measurement or host callback authority.

The quality runner executes at most 12 sequential frames in 30 seconds, including compilation and host observations. It follows controls/entities from each returned frame, trying slider endpoints, an enabled button and an entity, then bounded sequential actions. It carries the validated returned state forward, so a bug appearing after repeated actions can be detected. Source bindings, inputs, state, event domains and frame budgets still use the existing lifecycle. Empty `{}` inputs are explicit; malformed initial values fail before execution. Caller cancellation and the overall deadline race every asynchronous stage, including a hanging host callback.

A legitimate empty sequence with an enabled Add control is useful. An empty scene without usable output/control is a failure; promises of interaction are checked at initialization, while a completed process may legitimately disable controls later. Guest loops reached after repeated actions return a bounded execution failure. The SDK currently exposes event-driven frames, not arbitrary CSS/requestAnimationFrame animation. The runaway fixture tests hostile repeated computation rather than claiming coverage of an unsupported autonomous-animation API.

## Measurements and diagnostics

The trusted browser measures actual SVG text bounds. The shared renderer uses `1rem` labels, including enlarged reader text. Bounds include the real glyph box and the host's 24-unit viewBox padding; checking only the text anchor would miss clipping. No synthetic character-width estimate is reported as a browser measurement. Pure reference tests can omit measurements and explicitly record `textMeasurements:not-run`.

DOM audits check page overflow while permitting the diagram/table's deliberate scroll regions; interactive target dimensions (44 px), enabled keyboard reachability, flat CSS foreground/background contrast, host-control presence and unexpected infinite motion under a reduced-motion preference. Browser CSS color conversion supports modern color syntax and alpha compositing. These inspections are bounded engineering checks, not a comprehensive accessibility certification. Disabled scripted controls are size-checked; manual native-browser actions separately verify actual keyboard operation. Contrast checks do not evaluate arbitrary images or certify every graphics element.

The lab records actual viewport dimensions and can set the real root font to 200%. It counts console errors, window errors and unhandled rejections only during an explicit run, forwards console messages normally and retains no error arguments or stack strings. Host Stop, Close and source navigation remain outside the artifact's drawing and control declarations. Source return handles dialog focus restoration and aligns the beginning of a long source card in view.

Diagnostics contain a finite code, host/artifact scope, failing step and optional mark/control indices and viewport. They contain no copied labels, source values or exception text. Reports include artifact identity and schema version, content/source hashes, SDK version, scenario coverage and measurement status. Screenshots in the captured suite have file hashes and are observations, not hidden scientific assertions.

## Muse integration

After admission and initial smoke scenarios, candidate checks reuse the admitted adapter for the sequential quality gate. Trusted host text measurement supplies real bounds. Quality failures, reports and skipped coverage remain inspectable in the attempt history. New candidates cannot be saved through the Muse panel until compiler, runtime and quality checks pass; diagnostic inspection and downloads remain available. Previously accepted figures are retained rather than silently removed.

Actionable artifact failures such as clipped text, blank scenes and unavailable declared controls can enter the original bounded repair authorization. The server validates the exact preceding candidate and strict diagnostic schema. Host layout faults, missing measurement infrastructure, cancellation, integrity errors and resource contention never authorize another paid repair. Passing quality does not promote scientific evidence or accept a candidate automatically.

## Captured evidence

`npm run check` passes TypeScript, **355 tests** and production build. Focused tests exercise all four broken fixtures, real restricted compilation/execution, sequential growth, empty/invalid inputs, valid completion, strict diagnostic privacy, compiler classification and hanging callback/compilation cancellation/deadlines. A server test accepts bounded artifact quality feedback and rejects host faults or injected label strings before another paid call.

[Chromium154/Linux suite](../data/artifact-quality-browser.json) retains the actual observations and [screenshots](../data/artifact-quality/):

- Healthy 320px and 1280px layouts complete 12 frames with no diagnostics or logged errors.
- Clipped label, unreachable control, blank-after-action and runaway fixtures fail with their expected finite codes and steps (0, 0, 1 and 2).
- At 320px/200% text, the first run exposed a real host button overflow. That failed report/screenshot is retained. Width constraints fixed the host buttons; the repeated healthy run passes all 12 frames without page overflow.
- Native Enter activates an SVG entity and exposes its source action. Source return opens/focuses the quoted passage. The lab's host source action closes the dialog and focuses its card, with the first line visible even at 200%.
- Stop interrupts local checks while Close/source stay enabled. The lab makes zero generation API requests. No infinite host animation was observed; native reduced-motion preference was false, so another preference/platform is not claimed certified.

Routine verification made no paid model calls and used no held-out scientific papers. Layout measurements depend on browser, font and renderer versions. They are not participant/expert evaluation, scientific references or proof that an arbitrary future artifact is usable. Persistent cache/report replay is the next PP-099 boundary.
