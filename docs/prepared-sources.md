## Selection and fidelity

The reading fixtures contain **selected original passages**, about two thousand words across both sources, in their original order. They are not complete normalized editions. Complete originals remain available as local PDFs. Source paragraphs, manually transcribed equations and original-figure placeholders are all source blocks; any new pedagogical content must be rendered separately by the application.

The placeholder does not substitute a newly generated algorithm for the source. ## Preparation procedure and modifications

1. Download the pinned publisher PDFs, inspect license notices and record hashes.
2. Extract their text page by page using `pdftotext -layout`, preserving physical PDF page indices (the article page labels are respectively 23:n and 63:n).
3. Select original paragraphs by explicit source boundaries. Join typeset line wraps and correct obvious extraction-only hyphen breaks. Do not replace the authors' prose with an explanation generated by a model.
4. Inspect original page images for the priority-map specification, Dijkstra invariants and Powersort node-power notation. Transcribe those mathematical expressions to TeX and retain source-page metadata.
5. Correct extraction artifacts in primed type variables (`'a`, `'v`), primed values, non-membership (`∉`), superscripts, footnote markers and Method 2′. These are disclosed presentation modifications, not new scientific assertions.
6. Retain original figures/pseudocode as page-linked placeholders rather than claiming a lossless image/vector extraction. Captions are from the original with equivalent typography normalization.
7. Validate every document/anchor with the shared contract, then store attribution and selection coverage next to the document.

Source bibliographic numbers and footnotes still refer to the full original. Equations have normalized spacing/function-application notation. No source HTML is passed through to the UI. The `coverage` field and extraction warnings must remain visible to the reader; the original PDF link is the fallback for unselected material.

## Validation

`tests/papers.test.ts` validates both source contracts, every illustration anchor, increasing page order, attribution/edition identity, the critical distances-only/Powersort/run-definition passages and bundled-PDF checksums. Figure/pseudocode references must point to the original page. These tests protect the prepared source content and provenance; they do not certify that a scientific algorithm or experiment has been reproduced.

```sh
npx tsx --test tests/papers.test.ts
```

A true generic PDF/arXiv extraction pipeline, a full normalized version of either original and actual engine/scientific validation belong to their own later or parallel issues. The three held-out papers from the corpus have not been used to tune these selections or figure placements.
